# AI Rules

## Language

- Always use TypeScript.

## Architecture

- Prefer Server Components.
- Avoid unnecessary Client Components.

## Markup

- Use semantic HTML.
- No duplicated code.

## Styling

- Use shadcn/ui.
- Use Tailwind CSS.
- Use Motion for animations.
- Accessibility must meet WCAG AA.
- Do not use inline styles.

## Code Quality

- Keep components under ~250 lines where practical.

## Verification

Always run before marking work complete:

```sh
npm run lint
npm run build
```
